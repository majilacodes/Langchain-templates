## Overview

This repository contains code examples and tutorials for learning LangChain, a framework for developing applications powered by language models.

## Requirements

- Python 3.10+
- Poetry for dependency management

## Setup

1. Clone the repository
2. Install dependencies:
   ```
   poetry install
   ```
3. Set up your environment variables in `.env`:
   ```
   OPENAI_API_KEY=your_key_here
   ANTHROPIC_API_KEY=your_key_here
   GOOGLE_API_KEY=your_key_here
   FIRECRAWL_API_KEY=your_key_here
   TAVILY_API_KEY=your_key_here
   ```

## Contents

- Basic LangChain concepts
- RAG (Retrieval Augmented Generation) implementations
- Agents and Tools
- Integration with various LLM providers (OpenAI, Anthropic, Google)
